Features

# ========================================== # ASSIGNMENT 12 # Static Website with Public Access # ========================================== # ========================================== # STEP 0 # Start Existing EC2 Instance # ========================================== # AWS Console → EC2 → Instances # Select instance # Instance State → Start Instance # Copy Public IPv4 Address # Example: # 98.82.187.249 # ========================================== # STEP 1 # Create Assignment12 Folder In GitHub # ========================================== # Create: # Assignment12/index.html # Assignment12/style.css # ========================================== # STEP 2 # Add HTML and CSS Code # ========================================== # index.html → website structure # style.css → website styling # ========================================== # STEP 3 # Open Terminal # ========================================== cd ~/Downloads # ========================================== # STEP 4 # Check PEM File # ========================================== ls # ========================================== # STEP 5 # Give Permission To PEM File # ========================================== chmod 400 lp2.pem # ========================================== # STEP 6 # Connect To EC2 Using SSH # ========================================== ssh -i lp2.pem ubuntu@98.82.187.249 # ========================================== # STEP 7 # Go To Home Directory # ========================================== cd ~ # ========================================== # STEP 8 # Remove Old Cloned Repository Copy # SAFE: Does NOT Delete GitHub Repo # ========================================== sudo rm -rf LP2 # ========================================== # STEP 9 # Clone Updated GitHub Repository # ========================================== git clone https://github.com/joshitanisha/LP2.git # ========================================== # STEP 10 # Open Assignment12 Folder # ========================================== cd LP2/Assignment12 # ========================================== # STEP 11 # Remove Old Website Files # ========================================== sudo rm -rf /var/www/html/* # ========================================== # STEP 12 # Copy Assignment12 Files To Apache Server # ========================================== sudo cp -r * /var/www/html/ # ========================================== # STEP 13 # Open Website In Browser # ========================================== # Browser: # http://98.82.187.249 # ========================================== # IMPORTANT VIVA POINTS # ========================================== # Public Access: # Website accessible through internet # Public IP: # Internet-facing server address # Apache: # Web hosting server # Port 80: # Used for HTTP communication # GitHub: # Used for version control and deployment # Deployment: # Making website accessible online # SSH: # Secure remote login into EC2 # ========================================== #
